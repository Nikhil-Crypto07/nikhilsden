# Traffic Forecasting

A machine learning project for forecasting vehicle traffic using historical traffic data.

## Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Traffic visualization
- Time Series Forecasting

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
